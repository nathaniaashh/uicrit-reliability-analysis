# UICrit Reliability Analysis

This repository contains the analysis code and supporting outputs for a study of inter-rater reliability and design critiques in the UICrit dataset.

## Repository Contents

- `a1_audit.py` — initial data audit
- `a2_rq1.py` — RQ1 analysis
- `a3_final.py` — topic analysis
- `a3_pilih_k.py` — topic-number selection
- `a4_models.py` and `a4_prep.py` — additional analysis scripts
- `a5_sens.py` — sensitivity analysis
- `a6b.py` and `a6_clf.py` — additional analysis scripts
- `requirements.txt` — Python dependencies
- CSV files — supporting analysis tables
- PNG files — analysis figures

## Requirements

Python 3.12.0 and the packages listed in `requirements.txt`.

## Running the Analysis

1. Create and activate a Python virtual environment.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run the analysis scripts in the order described in the study's methodology.

Please refer to the individual scripts for implementation details.

## Dataset

The study uses the UICrit dataset. See the [official UICrit repository](https://github.com/google-research-datasets/uicrit) for dataset documentation and access information.

## Reproducibility

The repository provides analysis code and supporting outputs for transparency and reproducibility. Package versions and execution instructions should be checked against the final analysis environment.
